Main Computer — Secure Login

Sign in to Main Computer

Select your saved MC proof file. Your browser will use the file locally to answer a one-time authentication challenge; the permanent key is never uploaded.

The proof appears in your default user folder as AAA_AUTH_MAIN_COMPUTER.json, near the top when sorted by name. Select it and click Open. If needed, copy the full path above and paste it into the Open dialog. Do not upload the proof to any other website.
Checking your MC session…
Authentication uses the HTTPS endpoint. The session survives normal browser and MC restarts until it expires or is revoked.
