# Hawk–Dove prompt-format transition probe (v2)

This updates `tools/nanojev_hawk_dove_baseline_probe.py` IN PLACE. It is a strictly read-only evaluation of the existing `mix_v4` checkpoint. It does not populate a task bank, change training, save weights, create curriculum schedules, or modify the checkpoint. Synthetic jacket rubrics remain synthetic, not validated optimal captain behavior.

## Why

The step-72,500 six-case probe showed 50% joint 5%-tolerance recovery with the **native registered prompt**, but 0% for the new L00. The old head reads `XXXXXX`, `YYYYYY`, native operation prose, and an `Answer:` terminator. The new L00 had simultaneously shortened the register labels, changed the operation grammar, and changed other formatting. We need to measure each transformation independently before choosing a training starting rung.

## How to run on the current checkpoint

From `C:\Users\subsi\main_computer` after applying the patch:

```powershell
$py = 'C:\Users\subsi\NanoJev\.venv\Scripts\python.exe'

# No model loading: show the full raw captain story FIRST, then the
# old ladder and exact native-format contrast prompts.
& $py -m tools.nanojev_hawk_dove_baseline_probe `
  --suite bridge --captains c01 --preview

# Small, targeted GPU test, safe for the 6 GB RTX 3060: one prompt per batch.
& $py -m tools.nanojev_hawk_dove_baseline_probe `
  --suite bridge `
  --checkpoint latest `
  --device cuda `
  --dtype float16 `
  --captains c01,c03,c05 `
  --scenarios s01 `
  --states-per-scenario 2 `
  --batch-size 1 `
  --answer-mode paired `
  --report .\runtime\hawk-dove-format-bridge-72500.json
```

`--checkpoint latest` always means the checkpoint actually present at run time, so it can be later than step 72,500. The report records the step and SHA-256 hashes.

The small run evaluates 6 distinct canonical captain–scenario–state cases, 15 formatting contrasts, and both `Answer:` present/absent, for 180 unique prompts. Each prompt is evaluated with the original operation-ID side channel and with a neutral operation ID, using the same frozen backbone and trained heads as before. Inference is batch-size 1, with `torch.no_grad()`.

For a direct comparison against the earlier L00–L10 ladder, use `--suite both`, which also evaluates the exact two legacy control formats. This runs more prompts and can take longer. `--suite ladder` preserves the original probe mode. With `--answer-mode present`, only the trained `Answer:` suffix is used; `--answer-mode absent` tests only its removal.

## Controlled ablations

| ID | Parent | One isolated change (except indicated combined controls) |
|---|---|---|
| B00 | — | Exact `registered_logbar` text generated by `mix_v4.curriculum_prompt()` |
| B01 | B00 | Rename `XXXXXX` to `X`, consistently in assignment and operation |
| B02 | B00 | Rename `YYYYYY` to `Y` |
| B03 | B01 | Also rename `YYYYYY` to `Y` |
| B04 | B00 | Change only the operation field name from `operation:` to `OP:` |
| B05 | B00 | Change the subtraction instruction to `XXXXXX - YYYYYY` |
| B06 | B00 | Combined symbolic `OP = SUB (...)` control |
| B07 | B03 | Combined symbolic OP with shortened registers |
| B08 | B00 | Add a short situation tag without changing numeric registers |
| B09 | B08 | Add the same qualitative state as explicit categorical labels |
| B10 | B09 | Add the captain's short jacket |
| B11 | B00 | Add the complete natural-language jacket and scenario, with numeric registers intact |
| B12 | B11 | Replace only the X register with `J(captain jacket, situation)` |
| B13 | B11 | Replace only the Y register with `K(opponent evidence, situation)` |
| B14 | B12 | Replace Y too, so both quantities must be inferred from semantic evidence |

Every row also has a paired `Answer:` terminator contrast. The JSON contains token counts, prompt hashes, targets, raw predictions, X and Y errors, operation accuracy, decision sign, paired X/Y error deltas, and condition (`training` oracle ID vs. `neutral` ID). Unscorable prompts over the checkpoint's 256-token limit are marked and excluded, *never silently truncated*. The full captain description always begins the printable preview.

B00 is the authoritative reference. B01–B07 distinguish *format-transfer* failure from numerical scale failure; B08–B11 test whether context distracts an otherwise correctly prompted head; B12–B14 test the new unlearned semantic projection. Do not equate a high decision-sign score with accurate X/Y reconstruction.

## Interpretation

A six-case test is diagnostic only. To qualify a curriculum rung, run at least 30 distinct captain–scenario–state cases (for example, 10 captains × 3 states for one scenario), and use held-out states as well. We do not populate the next training database or change the active scheduler until the bridge probes show which exact transformation produces the first large regression. Nothing in this code claims that the synthetically calibrated J/K rubric is behaviorally optimal.
