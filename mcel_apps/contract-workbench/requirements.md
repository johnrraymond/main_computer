# Contract Operations Workbench

This package is the forward specification and TDD acid application for the next MCEL application-development boundary. Its application definition and explicit contracts are authoritative even where the current runtime cannot execute them. Runtime-dependent acceptance remains planned until MCEL closes the package's named bridges.

```mcel-acceptance
id: contract-workbench.acceptance.complete-application
app: contract-workbench
status: planned
requires:
  - typed form payload commits one stable keyed item
  - invalid form payload is refused and conditionally displayed
  - keyed update and remove affect only the selected item
  - filter and sort change local and derived views without canonical mutation
  - streamed quote progress remains provisional until one commit
  - quote cancellation closes provisional work without canonical mutation
  - stale, duplicate, prohibited, undeclared-write, and failed-postcondition operations are refused
  - dynamic collection observation matches keys, order, fields, and controls
  - two mounted instances remain isolated
  - every declared operation has positive, refusal, browser, and recovery coverage where required
```
