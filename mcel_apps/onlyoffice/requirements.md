# ONLYOFFICE
The paired MCEL application owns workbook inventory, selection, creation, upload, save, status, reload and explicit selected-cell code attachment. The external Document Server owns spreadsheet editing. The privileged MCEL page must never load Document Server JavaScript; only the isolated HTTPS editor origin may receive configuration via the existing origin-, source- and channel-bound protocol. Existing authenticated workbook APIs, storage, document keys, callback JWT, revision fencing and durable journal remain authoritative. A force-save request is not a durable-save receipt. Switching workbooks must serialize editor lifecycle operations. The Advanced pane provides the shared embedded Chat Console and code comments, not arbitrary execution on the application origin. Browser acceptance with the actual Document Server is required before certifying runtime parity.
