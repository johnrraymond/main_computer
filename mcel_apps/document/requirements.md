# Document Editor
The canonical paired application consumes one registry-mounted rich-text Document Surface. The element owns document content, history, selection, pagination, formatting and geometry. The application owns document identity, backend draft persistence, AI proposals and export. The native document workspace fills its available viewport with stationary controls and a single document scroll owner. Library/outline and AI panes may be independently collapsed. Document paint must be independent of application chrome. Explicit saves use optimistic concurrency in the native draft store and never overwrite original source. Unsupported imports refuse without changing the active document. AI proposals require revision-checked explicit apply. No legacy application parity or legacy draft import is required.
