# G1-0075 — Candidate Coverage and Structured-Set Learning Bake-off

## Governing result

G1-0074 selected `structured_set_maxmargin` independently for Oracle-Fabric
and legacy G1. With both G1 heads frozen, the exploratory full-DEV exact counts
were **37/80** (cutover) and **39/80** (legacy). Its oracle-assisted upper bound,
*when restricted to the G1-0074 candidate inventory*, was **50/80** (cutover)
and **55/80** (legacy). For cutover, the 64/80 DEV gate is therefore unreachable
by merely reordering the identical candidate set.

This is the scientific reason for G1-0075: **separate missing candidate
coverage from poor assignment/selection of candidate objects**. A candidate
coverage ceiling is a *label-assisted diagnostic* and is not a trained decoder.
The 71/80 gold-coordinate oracle reported previously used a different,
stronger intervention that supplied true span coordinates; it is not normal
inference and is not directly comparable to the old reachable-lattice ceiling.

## Four-arm competition

| Arm | Candidate source | Trained components | Assignment |
|---|---|---|---|
| `structured_set_maxmargin` | Exact original G1-0074 candidate inventory | **None** (reuses reported frozen 32-vector) | Exact G1-0074 structured-set Viterbi |
| `frozen_score_candidate_expansion` | All valid frozen-logit token spans, competing non-null types, deterministic score-budgeted expansion | None | Frozen G1-0074 structured-set weights, exact old scores preserved |
| `learned_whole_span_proposal` | Same expanded inventory | A **local supervised** 18-feature whole-span admission model, deterministic zero initialization | G1-0074 structured-set weights frozen |
| `joint_proposal_structured_set` | Same expanded inventory | Two **jointly updated** residual blocks (18 proposal + 32 full-set feature dimensions) trained against loss-augmented complete sets | Global structured-set Viterbi |

The frozen logit source, frozen head weights and Qwen/LoRA backbone remain
unchanged for all four arms. **New candidates are generated by reading every
valid token span and every semantic type from the actual frozen span logits.**
This is not re-ranking G1-0074's original candidates: `Option` records for
previously absent span/type coordinates are constructed before supervision is
attached. All original candidate options and their G1-0074 scores are preserved
**exactly**, so loss/benefit of the new proposal pathway can be measured fairly.

A fixed fail-closed upper budget of 4,096 total candidates per prompt is applied;
old candidates take priority. Remaining candidates are selected by a declared
frozen logit ranking, never gold labels. The report records raw valid-span
coordinate coverage, expanded-but-budgeted candidate coverage, and original
G1-0074 coverage as **three different oracle regimes**. If the budget or
span-validity mask excludes required gold coordinates, that deficit is reported
and never silently credited to the selector.

The local proposer learns a balanced supervised whole-span inclusion rule from
newly generated gold-matched and frozen-hard-negative proposals. The joint
competitor instead learns *both* proposal and full-set residuals from a
loss-augmented structured hinge. It is not a second local cross-entropy fit.
All weights have deterministic zero initialization; no random trainable
initialization is introduced. The original 0074 structured parameters remain
pinned and unchanged.

## Data separation and verification

The same family-stratified **48 FIT / 16 SELECTION / 16 AUDIT** DEV partition as
G1-0073 and G1-0074 is used, for accurate within-lineage comparisons. The
32-case historical CHALLENGE cohort remains previously examined. Candidate
construction and all inference functions are label-blind; gold enters only
training, evaluation and the separate oracle ceiling. Selection uses the 16
selection cases and requires exact-set nonregression, F1 nonregression, full
actor/action/quantity/outcome recall retention and ≤0.5 percentage-point
precision decrease. The audit is evaluated only after arm selection. **A
within-project audit split and previously inspected challenge do not provide
independent certification**, regardless of score.

Use `--independent-dataset` to evaluate a separately created, canonical,
nonoverlapping external G1 graph curriculum. The runner refuses any exact
prompt overlap, verifies file hashes and reports the provenance limitation.
If no such dataset is supplied, the runner explicitly records that independent
validation was not performed; no gate or promotion may change.

The predecessor **G1-0074 and G1-0073** `report.json` files are mandatory.
G1-0074 must say that both models selected `structured_set_maxmargin`.
G1-0073 pins **different** G1-0071 source lattices for the cutover and legacy
models; silently substituting the shared G1-0072 decoder name as the lattice
prior would change the candidate inventory and invalidate the comparison.
The SHA-256 of G1-0073 is pinned by G1-0074, and the runner verifies it. Its checkpoint/dataset lineages, training
configuration, and each split's original control object counts, by-kind
metrics, and complete exact sets are checked for parity. An additional full-DEV
parity check protects the 37/80 and 39/80 baselines. Existing reports and
checkpoints are never overwritten. Every report includes paired recovered and
lost correct objects, new and removed false objects, exact case transitions,
per-arm selection/audit/historical-challenge/external scores, fitted weights,
oracle candidate ceilings and provenance hashes.

## Interpretation

1. If the **expanded reachable oracle ceiling stays below the G1 gate**, the
   proposal budget or frozen G1 span-validity and representation limits must
   be changed or trained; more decoder optimization alone cannot certify G1.
2. If the ceiling improves but the inference arms fail, **proposal and
   structured-set learning have not closed the admission/selection gap**.
3. If a selected arm improves on DEV-SELECTION but not on the audit or external
   set, label it an exploratory nontransferring result, not a replacement.
4. If coverage and exact-set performance transfer onto **new provenance-
   independent examples**, use them to design a prospective sealed
   certification test; never retroactively promote this exploratory bake-off.

**Hard invariants:** both G1 heads frozen; Qwen and source adapter frozen; no
changes to certification thresholds, runtime decoding, any other stage, G2
weights, deployment, source-training checkpoints, or production promotion.
